# Backend · общая служба поиска трендов

Node.js + TypeScript + Fastify. Независимая служба для сайта, будущего Telegram-адаптера и предметных агентов. Обязательных платных API нет.

## Запуск

Node.js 24 LTS рекомендуется, версия указана в `.nvmrc`. В отдельном терминале из корня репозитория:

```sh
cd backend
npm ci
npm run dev
```

API: `http://127.0.0.1:8787`. Затем запустите frontend по его инструкции: Vite направляет `/api` в backend. Если меняете порт API, обновите proxy в `frontend/vite.config.ts`.

```sh
npm test       # Проверки без интернета и реальной модели
npm run build # Проверка типов и компиляция
npm start     # Запуск собранного API после build
```

## API

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/api/health` | Проверка состояния |
| GET | `/api/trends/capabilities` | Источники и наличие конфигурации AI |
| POST | `/api/trends/research` | Исследование с публикациями, сигналами и необязательным AI-разбором |

Пример реального запроса:

```sh
curl http://127.0.0.1:8787/api/trends/research \
  -H 'Content-Type: application/json' \
  -d '{"domain":"health","query":"силовые тренировки","windowDays":7,"limit":6,"mode":"live","enableAi":false}'
```

- `domain`: `all`, `planning`, `finance`, `health`, `wardrobe`.
- `query`: до 160 символов; пустая строка означает все темы выбранной области.
- `windowDays`: 1–30; сравниваются два соседних окна одинаковой длины.
- `limit`: 1–10 тем.
- `mode`: `live` по умолчанию; `demo` нужно передать явно.
- `enableAi`: `false` по умолчанию.

Для `planning` пока нет живых источников — API вернёт 422. В деморежиме область доступна. Нет скрытого переключения с live на demo при ошибке сети.

## Подключение к другим агентам

Типы запросов и ответов: `shared/trends.ts` в корне репозитория. Другой модуль может вызвать HTTP API или зарегистрировать инструмент напрямую:

```ts
import { TrendResearchService } from './src/trends/service.js'
import { createTrendTool } from './src/trends/tool.js'

const tool = createTrendTool(new TrendResearchService())
// tool.name, tool.description, tool.inputSchema — метаданные инструмента.
const report = await tool.execute({
  domain: 'wardrobe', query: 'гардероб', mode: 'live', windowDays: 7,
})
```

Импорты в примере указаны относительно `backend/`. Под конкретный агентный фреймворк потребуется небольшой адаптер регистрации; сама служба от фреймворка не зависит.

## Необязательный AI-разбор

По умолчанию модель не вызывается. Подготовлен адаптер локального Ollama, но сам Ollama и модели в проект не устанавливаются.

Если Ollama уже настроена и нужная текстовая модель установлена, скопируйте `.env.example` в `.env`, укажите её точное имя в `TREND_LLM_MODEL` и перезапустите API. При необходимости задайте `TREND_LLM_URL`. На сайте станет доступен флажок AI-разбора. `configured=true` означает наличие настройки, а не гарантию доступности модели.

Разбор запускается только при `enableAi=true`. Передаём ограниченный набор публикаций; требуем JSON по схеме и проверяем, что ссылки относятся к переданным темам и материалам. Неуспех модели возвращает `analysis.status=unavailable`, сохраняя результат обычного поиска.

Для другого провайдера реализуйте интерфейс `TrendAnalyzer` из `src/trends/analyzer.ts` и передайте адаптер в конструктор службы. Текущий рабочий процесс фиксирован: автономный выбор инструментов и беседы нескольких агентов не добавлены.

## Границы первой версии

- Источники задаются на сервере в `src/trends/catalog.ts`. Клиент не передаёт произвольные URL.
- Сейчас загружаем RSS, не сканируем произвольные страницы сайтов и весь веб.
- Живые ленты ограничены по глубине. Рост упоминаний в выборке не равен доказанному глобальному тренду.
- Группировка основана на явном словаре тем и двуязычных ключевых словах. Для новой темы нужно расширить словарь или добавить отдельную модель группировки.
- Кэш лент хранится в памяти 10 минут. Долговременная история, ежедневные снимки и автоматическое расписание пока не реализованы.
- API слушает только loopback. Для сетевого развёртывания отдельно потребуются маршрутизация и авторизация пользователей.
