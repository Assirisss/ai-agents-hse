# Frontend · Личный ассистент

Базовое приложение на React, TypeScript и Vite. Четыре вкладки с пустыми разделами — общая точка старта команды. [Основа сборки — Vite](https://vite.dev/guide/).

## Запуск

Используйте Node.js 24 LTS (версия указана в `.nvmrc`) и npm. Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite, обычно `http://localhost:5173`.

```sh
npm run lint     # Проверка кода
npm run build    # TypeScript и сборка в dist/
npm run preview  # Локальный просмотр сборки
```

## Куда встраивать свою часть

| Раздел | Папка | Входной компонент |
| --- | --- | --- |
| Дела и календарь | `src/modules/planning/` | `PlanningPage.tsx` |
| Финансы и инвестиции | `src/modules/finance/` | `FinancePage.tsx` |
| Спорт и питание | `src/modules/health/` | `HealthPage.tsx` |
| Гардероб | `src/modules/wardrobe/` | `WardrobePage.tsx` |

Замените содержимое своего входного компонента и добавляйте рядом собственные компоненты, типы и CSS Modules (`*.module.css`). Сохраните его `default export`: вкладка уже подключена в `src/App.tsx`.

Общая оболочка и переключение вкладок — `src/App.tsx` и `src/App.css`. Общие базовые стили — `src/index.css`. Пустые разделы используют общий компонент `src/components/ModulePlaceholder.tsx`, который можно заменить в своём модуле.

Панели скрываются атрибутом `hidden`, сохраняя состояние компонентов при переключении. Они остаются смонтированными: будущие запросы данных и фоновые эффекты запускайте осознанно. Вкладки поддерживают мышь и клавиатуру (стрелки, Home, End).

## Работа в команде

1. Создайте ветку для своей задачи, например `feature/finance`.
2. Работайте преимущественно в папке своего модуля.
3. Перед отправкой выполните `npm run lint` и `npm run build`.
4. Отправьте ветку и откройте Pull Request в `main`.

При изменении зависимостей коммитьте `package.json` вместе с `package-lock.json`. Backend, агенты, API и Telegram пока не подключены.
