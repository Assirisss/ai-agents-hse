# Frontend · Личный ассистент

React + TypeScript + Vite. Graphite-оформление и боковая навигация перенесены из пользовательского проекта SecondBrain. Четыре предметных раздела и общий инструмент поиска трендов.

## Запуск

Node.js 24 LTS и npm. Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite, обычно `http://localhost:5173`. Для поиска трендов запустите также [backend](../backend/README.md) в отдельном терминале. `/api` проксируется на `http://127.0.0.1:8787` в dev и preview.

```sh
npm run lint
npm run build
npm run preview
```

## Модули

| Раздел | Папка | Входной компонент |
| --- | --- | --- |
| Дела и календарь | `src/modules/planning/` | `PlanningPage.tsx` |
| Финансы и инвестиции | `src/modules/finance/` | `FinancePage.tsx` |
| Спорт и питание | `src/modules/health/` | `HealthPage.tsx` |
| Гардероб | `src/modules/wardrobe/` | `WardrobePage.tsx` |
| Поиск трендов | `src/modules/trends/` | `TrendsPage.tsx` |

Каждый участник развивает свою папку и сохраняет `default export` входного компонента. Используйте CSS Modules или префиксы классов для изоляции стилей. Общая оболочка — `src/App.tsx`, боковое меню — `src/components/Sidebar.tsx`, визуальные токены — `src/index.css` и [брендбук](../design/BRAND.md).

Разделы обёрнуты в React Activity: состояние сохраняется при переходах, эффекты скрытого раздела очищаются и восстанавливаются при открытии. Подробнее — [React Activity](https://react.dev/reference/react/Activity). Асинхронные эффекты должны корректно отменять свои запросы.

## Подключение трендов

Используйте HTTP API службы; типы находятся в `shared/trends.ts` в корне репозитория. Экран трендов использует тонкий клиент `src/modules/trends/api.ts`. Контракт и пример подключения к агенту — в [инструкции backend](../backend/README.md).

Не подключайте серверный RSS-парсер, переменные окружения модели или backend-модули напрямую в браузерную сборку. Telegram и агенты отдельных сфер пока требуют своих адаптеров.

## Работа в команде

1. Ветка на задачу, например `feature/finance`.
2. Изменения преимущественно внутри своего модуля.
3. Перед отправкой: `npm run lint` и `npm run build`.
4. Отправьте ветку и откройте Pull Request в `main`.

Если меняете зависимости, коммитьте `package.json` вместе с `package-lock.json`. [Документация Vite](https://vite.dev/guide/).

## Финансы

Раздел `src/modules/finance/` реализует учёт, черновики и фото чеков, помощника, акции MOEX и настройки Telegram. Нужен backend с Postgres. Модель и токен бота хранятся только на сервере. [Запуск и сценарии](../docs/finance.md).

### Проверка финансовых форм

```sh
npx playwright install chromium
npm run test:finance-ui
```

Проверки поднимают отдельный Vite на `127.0.0.1:5178` и подменяют все API-запросы тестовыми ответами. Рабочий backend и личные данные не используются. Проверяются обновление суммы после внешнего редактирования, сохранение несохранённых правок при конфликте и отправка версии черновика при сохранении/подтверждении. Для установленного Chrome вместо загрузки Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` с путём к исполняемому файлу.
