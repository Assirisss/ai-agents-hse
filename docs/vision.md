# Идея проекта

Статус: черновик. Содержание уточняется по результатам обсуждения.

## Известный контекст

- Учебный проект по курсу «AI-агенты».
- В команде четыре человека.
- Сначала описываем идею и требования, затем переходим к реализации.
- Документация должна помогать участникам выполнять задачи с помощью своих AI-агентов.
- Код и документацию планируем хранить в GitHub.

## Проблема и пользователь

Личный ассистент объединяет информацию о разных сферах жизни человека. Сейчас проекты, учёба, спорт, питание, гардероб и другие дела ведутся в разных приложениях; данные разрознены, а общий контекст приходится поддерживать самому.

Замысел — единая точка взаимодействия с этими данными и действиями. Система учитывает информацию из разных сфер и помогает пользователю организовывать дела и находить полезные улучшения.

Открытые вопросы: кто первый пользователь, какие приложения он использует и какой конкретный результат нужен ему в первую очередь?

## Роль AI-агентов

Основной принцип, переданный автором со слов преподавателя: сначала максимально покрываем задачи детерминированной автоматизацией. AI добавляем только там, где задача не покрывается подходящими обычными правилами и алгоритмами.

Агент или оркестратор может появиться поверх работающих автоматизаций для оставшихся задач. Его необходимость и функции предстоит обосновать конкретными сценариями.

При описании каждой функции фиксируем:

1. Что выполняет обычный код: хранение, расчёты, правила, расписания, интеграции.
2. Какая часть остаётся нерешённой и почему для неё требуется AI.
3. Как проверяется результат и что происходит при ошибке.

Открытый вопрос: какие решения и действия выполняет агент, какими инструментами пользуется и где требуется участие человека?

Количество агентов пока не определено. Число участников команды само по себе не определяет число агентов в системе.
