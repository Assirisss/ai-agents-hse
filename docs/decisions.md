# Журнал решений

## 2026-10-17 — Приоритет детерминированной автоматизации

- **Статус:** принято по прямому указанию автора проекта.
- **Контекст:** преподаватель ожидает максимального покрытия задач обычными автоматизациями и обоснованного использования AI только в оставшихся задачах.
- **Решение:** начинаем с правил, алгоритмов, расписаний и интеграций. Для каждого применения AI отдельно описываем задачу, которую не удалось покрыть детерминированным способом. Агент или оркестратор добавляется поверх автоматизаций при наличии такой задачи.
- **Причина:** это основной принцип проекта, который необходимо показать в реализации и на защите.
- **Последствия:** в требованиях и архитектуре явно разделяем обычную автоматизацию и функции AI. Стек, количество агентов и состав MVP пока не выбраны.

## 2026-10-17 — Четыре продуктовых блока

- **Статус:** принято по прямому указанию автора проекта.
- **Контекст:** первоначальные 12 направлений слишком широки для текущего обсуждения и реализации.
- **Решение:** объединить проекты, задачи и календарь; сохранить финансы с инвестициями; объединить спорт и питание; сохранить гардероб. Контакты, отдельное планирование будущего и банк идей исключить. Утренний отчёт оставить дополнительной функцией; тренды рассматривать как общую возможность для разных сфер.
- **Причина:** сфокусировать структуру продукта вокруг четырёх областей.
- **Последствия:** это состав продуктовой концепции, а не обязательство реализовать все пожелания в первой версии. Место учёбы нужно уточнить. Четыре области не означают автоматически четыре агента.

## 2026-10-17 — Сайт, Telegram и собственные разделы учёта

- **Статус:** принято по прямому указанию автора проекта.
- **Контекст:** уточнены формат взаимодействия и отношение к существующим приложениям.
- **Решение:** основной интерфейс — сайт с адаптацией под разные форматы экранов, дополнительный — Telegram. Реализуем собственные разделы учёта. Проверяем проект на одинаковых данных.
- **Причина:** цель — учебный продукт с самостоятельной функциональностью.
- **Последствия:** нужно определить формат демонстрационных данных, профили пользователей и связь Telegram с сайтом. Общий прикладной слой предлагается в архитектурном документе, но пока не утверждён.

## 2026-10-17 — Вариант с диспетчером и специализированными сценариями

- **Статус:** предложено, решение автора ещё не получено.
- **Контекст:** обсуждается референс с Intent Router, специализированными агентами, инструментами и выбором моделей.
- **Предложение:** начать с обычного диспетчера, четырёх модулей, детерминированных функций и отдельных вызовов AI. Агентный планировщик или делегирование добавлять для подтверждённых сценариев.
- **Причина:** описанные операции преимущественно допускают известную последовательность; необходимость автономного агента в каждой области пока не показана.
- **Последствия:** сравнить варианты на одинаковых входных данных; конкретные критерии и состав первого набора ещё предстоит согласовать. [Подробности и референс](architecture.md).

## 2026-10-17 — Graphite и расположение из SecondBrain

- **Статус:** реализовано по запросу автора.
- **Решение:** перенести оформление и расположение из локального проекта SecondBrain: боковая навигация, чёрный фон, графитовые поверхности, тонкие линии и синий акцент. Четыре предметных раздела сохраняются; поиск трендов вынесен в общие инструменты.
- **Последствия:** [визуальные правила](../design/BRAND.md) зафиксированы в проекте; данные и функциональность другого проекта не переносились.

## 2026-10-17 — Общий поиск трендов без обязательного платного API

- **Статус:** требования подтверждены автором; первая версия реализована.
- **Решение автора:** нужны растущие темы и обзор материалов, выбранные открытые RSS-источники и сайты, без обязательного платного API.
- **Реализация первой версии:** серверный каталог RSS, детерминированный сбор и подсчёт упоминаний, общий API и инструмент для будущих агентов. AI-разбор необязателен; подготовлен адаптер локальной Ollama. Это фиксированный процесс, автономная оркестрация пока не нужна.
- **Последствия:** конкретные первые темы и частота обновлений уточняются. Сейчас поддержан запуск по запросу и работа с RSS; произвольные страницы сайтов, долгосрочная история и планировщик не реализованы. Рост описывает только полученную выборку. [Подробности](trends.md).

## Формат следующих записей

После обсуждения добавляем записи в формате:

- **Дата и название решения.**
- **Статус:** предложено / принято / заменено.
- **Контекст:** какую задачу или неопределённость решаем.
- **Решение:** что выбрали.
- **Причина:** почему это подходит проекту и какие есть ограничения.
- **Последствия:** что нужно сделать и какие вопросы остались.

Предложения и рабочие гипотезы не считаются принятыми решениями.
