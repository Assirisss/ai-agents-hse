# Общая LLM агентов · OpenRouter API

С 2026-10-18 исследователь трендов и стилист используют внешний OpenRouter API. В закрытом `backend/.env` задан существующий `OPENROUTER_API_KEY`, общий `OPENROUTER_MODEL=openrouter/free`; исследователь использует переопределение `TREND_OPENROUTER_MODEL=nvidia/nemotron-3-super-120b-a12b:free`. Ключ остаётся на backend.

`RUNPOD_LLM_ENDPOINT_ID` очищен. Подготовленный LLM endpoint Runpod сохранён для будущего перехода, но отключён: `workers.min=0`, `workers.max=0`. BiRefNet использует отдельный endpoint и продолжает обрабатывать фото. Настройки ниже описывают сохранённое развёртывание Runpod.

## Сохранённая модель Runpod

Модель: [Qwen/Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507), revision `cdbee75f17c01a7cc42f958dc650907174af0554`. Это небольшая текстовая instruct-модель без thinking-режима, с поддержкой инструментов и нескольких языков. Качество сложных исследований и рекомендаций ещё нужно оценивать отдельно; успешный вызов инструмента не равен проверке всех сценариев.

## Развёртывание

- Endpoint: `65zcbm5ojk45sz`, `graphite-agent-brain-qwen3-4b`.
- Официальный Hub worker: `runpod-workers/worker-vllm`, release `v2.29.0`, Hub release `cmuxgi0a3000407jv5igk1ezr`, template `277zl70k6j`.
- GPU pool `AMPERE_16`, один GPU; CUDA 13.0 требуется текущим образом worker. Stock RTX A4500 и serverless-цена $0,58/час активного GPU подтверждены каталогом Runpod при развёртывании 2026-10-18.
- Сейчас workers 0–0: запуск GPU отключён. При возобновлении — workers 0–1, idle timeout 1 секунда, FlashBoot. Постоянный worker, Pod и network volume не создаются. Модель загружается только на Runpod.
- Контейнерный диск 20 ГБ, контекст сервера 16 384 токена, одна активная последовательность, ответ приложения ограничен 1200 токенами. Eager mode сокращает компиляцию при старте.
- Исходные веса BF16: 4 022 468 096 параметров × 2 байта ≈ 8,04 ГБ. При запуске используются FP16; KV-кэш на 16K токенов ≈ 2,42 ГБ, дополнительно нужны активации и память движка. Этот расчёт позволяет выбрать небольшой GPU вместо стандартных 80-ГБ пулов Hub.

Полная конфигурация без секретов: [services/llm/runpod.json](../services/llm/runpod.json). Endpoint создан из Hub с явно выбранным маленьким пулом, а не с дорогим GPU по умолчанию.

Оплачивается время работы worker, включая загрузку модели и простой перед выключением. Точная цена запроса зависит от времени работы, не является фиксированной ценой за токены. Поэтому `usage.costUsd` в приложении остаётся `null`, пока нет фактических данных биллинга. Холодный старт может занимать несколько минут; FlashBoot ускоряет его по возможности. Кэш и доступный GPU не гарантируются.

## Подключение к агентам

Чтобы позднее включить Runpod, сначала установите у endpoint `workers.min=0`, `workers.max=1`, затем задайте в закрытом `backend/.env` и перезапустите backend:

```dotenv
RUNPOD_LLM_ENDPOINT_ID=65zcbm5ojk45sz
RUNPOD_LLM_MODEL=Qwen/Qwen3-4B-Instruct-2507
# RUNPOD_API_KEY — существующий серверный ключ, также используемый BiRefNet.
```

`backend/src/llm/runpod.ts` реализует существующий интерфейс `ResearchPlanner`. Один настроенный экземпляр используется агентом трендов и стилистом гардероба. Данные/инструменты этих агентов остаются разделены; общая модель не получает общей истории автоматически.

При заданном `RUNPOD_LLM_ENDPOINT_ID` Runpod имеет приоритет над OpenRouter/Ollama. Ошибка Runpod не переключает запрос на другой платный сервис. Чтобы явно вернуться к прежнему провайдеру, очистите ID и перезапустите backend.

Каждый ход создаёт ровно одну задачу `/run`, затем проверяет её через `/status/{id}`. Тело Runpod: `{input: {openai_route: "/v1/chat/completions", openai_input: {model, messages, tools, tool_choice, ...}}}`. Это [официальный контракт worker](https://github.com/runpod-workers/worker-vllm/blob/v2.29.0/src/handler.py). Он позволяет дождаться холодного старта без короткого лимита синхронного OpenAI-шлюза.

Вызовы инструментов и их `tool_call_id` сохраняются. Код инструментов выполняется в приложении, проверяет аргументы и права. Модель только предлагает вызовы. Транспорт ограничивает размер ответа, не передаёт провайдерские трассировки пользователю и пытается отменить задачу при закрытии интерфейса. Сетевая ошибка может помешать отмене; автоматический повтор оплачиваемой задачи отсутствует.

Для Runpod общий срок выполнения исследователя и стилиста увеличен до 5 минут с учётом холодного старта. Лимиты количества вызовов инструментов и модели не увеличены. Отмена пользователем продолжает действовать; тайм-аут браузерного клиента стилиста — 325 секунд.

npm run build
node scripts/check-runpod-llm.mjs
